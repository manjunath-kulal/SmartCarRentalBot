## How to Use

### Compilation
```bash
gcc -o car_rental "source code"
```

### Running the Application
```bash
./car_rental
```

### Menu Options
1. **View available cars and book** - Original car rental functionality
2. **Search companies at Vaishnavi Tech Park Bellandur** - New company search feature
3. **Exit** - Close the application

The application maintains all original car rental functionality while adding the requested company search capability.
